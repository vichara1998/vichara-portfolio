# ✨ Professional Portfolio

A vibrant personal portfolio designed to showcase my work as a Software Engineering Undergraduate at the Open University of Sri Lanka. This project blends modern frontend engineering, smooth motion graphics, and a polished layout to present my skills, projects, and experience in a memorable way.

---

## 🌟 About Me

I am a developer focused on building user-friendly, visually appealing, and high-performing digital experiences. This portfolio serves as a digital resume and a window into my passion for frontend development, design systems, and problem-solving through code.

---

## 🚀 Highlights

- Responsive, mobile-friendly portfolio layout
- Modern glassmorphism-inspired UI with gradient accents
- Smooth animations and micro-interactions powered by Framer Motion
- Structured content architecture for easy updates and maintenance
- Performance-oriented frontend setup with Vite and React

---

## 🛠️ Tech Stack

- React 18
- Vite
- Tailwind CSS
- Framer Motion
- JavaScript
- Custom hooks and modular component design

---

## 📦 Project Structure

```text
src/
├── components/     # Reusable UI sections and interface components
├── hooks/          # Custom logic such as theme handling and scroll tracking
├── sections/       # Portfolio sections like hero, about, projects, skills
├── assets/         # Static media and visual resources
├── data.js         # Centralized content and profile configuration
└── App.jsx         # Main application entry point
```

---

## ⚙️ Features

### 🎨 Frontend Excellence
- Component-based architecture for maintainability and reuse
- Elegant glassmorphism styling with gradient borders and layered backgrounds
- Motion-enhanced transitions that make the experience feel premium and alive

### 🔧 Engineering Strength
- `useTheme` for persistent light/dark theme handling
- `useScrollSpy` for active navigation highlighting
- Centralized data-driven content for easy portfolio updates
- Lightweight, fast build workflow with Vite

